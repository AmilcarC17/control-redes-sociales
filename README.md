# Control de redes sociales
PWA privada para AC Soluciones. Pensada para instalarse en iPhone desde Safari sin Apple Developer.

## Publicación gratuita
Sube el contenido de esta carpeta al repositorio de GitHub Pages. Luego abre la URL `https://TU_USUARIO.github.io/control-redes-sociales/` en Safari y usa Compartir → Añadir a pantalla de inicio.

Los datos de esta versión se guardan localmente en el dispositivo. Usa “Exportar respaldo” para guardar una copia JSON.
